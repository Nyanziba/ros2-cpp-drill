# 面向学生机器人竞赛的三个系列

- 日语：https://nyanziba.github.io/ros2-cpp-drill/robocon/index.html
- English：https://nyanziba.github.io/ros2-cpp-drill/en/robocon/index.html
- 中文：https://nyanziba.github.io/ros2-cpp-drill/zh/index.html

这三个系列假定比赛大约三分钟，例如 ABU Robocon 或 NHK 学生机器人竞赛。原有的 C、C++、ROS 2 和设计模式各章保持不变。代码和测试三种语言共用，只有读物和题目分成三种语言。

## 系列

| 系列 | 练习 | 内容 |
| --- | --- | --- |
| 图像处理 | `cv01` 至 `cv06` | 颜色、ONNX、数据集、速度、节点、视线 |
| 行为树 | `bt01` 至 `bt03` | 优先级、动作、回避 |
| 自主控制 | `nav01` 至 `nav03` | 航向、状态、路径 |

## 语言

- [图像处理](vision/README.md)
- [行为树](behavior-tree/README.md)
- [自主控制](autonomy/README.md)

## 顺序

```bash
./drill run cv01
```
