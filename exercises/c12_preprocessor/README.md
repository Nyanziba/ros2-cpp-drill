# c12 プリプロセッサとデバッグ 〔C言語編〕

C のプリプロセッサと `assert` マクロの使い方、そして C11 の `_Static_assert` を学ぶ課題です。

## ヘッダに 2 つのマクロと 1 つの構造体が既に入っています

`include/drill/macro_utils.h` は**編集しません**。以下のものが既に定義されています。

| 要素 | 説明 |
| --- | --- |
| `SQUARE(x)` | 求積マクロ（`(x) * (x)`）。**括弧の重要性を学ぶ** |
| `DOUBLE_SQ(x)` | 変数を 2 乗する複文マクロ。**`do { ... } while (0)` パターン** |
| `CanPayload` | 8 バイトの CAN ペイロード構造体 |
| `_Static_assert` | コンパイル時に `sizeof(CanPayload) == 8` を確認 |

## やること

編集するのは `src/macro_utils.c` だけです。以下の 2 つの関数を実装してください。

### `is_debug_mode()`

このファイル内で `DEBUG` マクロを定義し、デバッグモード（1 を返す）にしてください。

```c
#define DEBUG 1

int is_debug_mode(void)
{
  return DEBUG;
}
```

### `validate_port_id()`

ポート ID（受け取った `uint8_t`）が **1-8 の範囲内**かチェックしてください。

- **無効**（0 未満または 9 以上）なら `assert` で通知
- **有効**なら 1 を返す
- **無効**なら 0 を返す

```c
int validate_port_id(uint8_t port_id)
{
  assert(port_id >= 1 && port_id <= 8);
  return port_id >= 1 && port_id <= 8 ? 1 : 0;
}
```

**重要：マクロの引数は 2 回評価されるので、複数回チェックすることに気づいてください。**

## マクロの罠

### 求積マクロ `SQUARE(x)` の問題

```c
#define SQUARE(x) x * x  // NG：括弧が足りない
```

この場合、`2 + SQUARE(3)` は `2 + 3 * 3 = 11` ではなく `2 + 3 * 3` = ... となります。演算子の優先順位に注意。

### 複文マクロ `DOUBLE_SQ(x)` の問題

```c
#define DOUBLE_SQ(x) (x) = (x) * (x)  // NG：if の後で使うと文法エラー
```

```c
if (condition)
  DOUBLE_SQ(x);  // これが文法エラーになる可能性
```

**解決策**：`do { ... } while (0)` で包む。これで 1 つの文として扱われます。

```c
#define DOUBLE_SQ(x) do { (x) = (x) * (x); } while (0)
```

## `_Static_assert` について

C11 で導入された **コンパイル時アサーション**です。条件が偽なら コンパイルエラーを出します。

```c
_Static_assert(sizeof(CanPayload) == 8, "CanPayload must be 8 bytes");
```

**注意**：`assert` と違い、実行時ではなく**コンパイル時**に確認されます。リリースビルドでも消えません。

## つまずきポイント

- **マクロの引数は複数回評価される**：`SQUARE(i++)` は `i++ * i++` になります。副作用のある式は渡さない
- **括弧を忘れない**：マクロの引数や結果全体を括弧で囲むこと
- **複文マクロは `do { ... } while (0)` で包む**：セミコロンの後の動作が正しくなります
- **`_Static_assert` はコンパイル時**：デバッグビルドもリリースビルドも同じように動作します
- **ポート ID は 1-8**：0 や 9 は無効です
