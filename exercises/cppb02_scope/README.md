# cppb02 スコープと寿命 〔C++入門編〕

オブジェクトの寿命とスコープを理解します。

## やること

Tracer クラスを実装してください。コンストラクタ・デストラクタで global ログに追記します。

## 動かしてみる

```bash
./drill run cppb02
```

## つまずきポイント

- スコープを抜けるとき、オブジェクトは作成と逆順に破棄されます。
- RAII パターン：リソース取得時に初期化、破棄時に解放。
