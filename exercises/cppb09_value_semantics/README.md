# cppb09 コピーを数える 〔C++入門編〕

値のセマンティクスとコピーの効率を学びます。

## やること

`src/data.cpp` に次を実装してください。

1. コピーコンストラクタ：`copy_ctor_count` をインクリメント
2. コピー代入演算子：`copy_assign_count` をインクリメント
3. `process_by_const_ref()`：`const Data &` で受け取る（コピーを避ける）

## 動かしてみる

```bash
./drill run cppb09
```

## つまずきポイント

- コピーコンストラクタと copy-assign は別です。テストで個別に数えられます。
- `const &` パラメータを使うとコピーが避けられます。
- RVO（戻り値の最適化）によって、返却時のコピーが消える場合があります。

## テスト

```bash
./drill run cppb09
```

| テスト | 見ているところ |
| --- | --- |
| `CopyCtorが数えられる` | コピーコンストラクタ |
| `CopyAssignが数えられる` | コピー代入演算子 |
| `値渡しはコピーが起きる` | 値渡しのコスト |
| `ConstRefはコピーが起きない` | const& のメリット |
