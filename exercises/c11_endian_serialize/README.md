# c11 エンディアンとシリアライズ 〔C言語編〕

CAN プロトコルの仕様に基づいて、浮動小数点数と整数をリトルエンディアン形式で バイト列に変換し、逆に復元する課題です。

## 実装すること

`src/endian_serialize.c` に以下の 4 つの関数を実装してください。ヘッダ（`include/drill/endian_serialize.h`）は**編集しません**。

| 関数 | 役割 |
| --- | --- |
| `write_float_le` | `float` をリトルエンディアンで 4 バイトに分解し、指定オフセットから `data[]` に書き込む |
| `read_float_le` | リトルエンディアンで読んだ 4 バイトを `float` に復元する |
| `write_uint32_le` | `uint32_t` をリトルエンディアンで 4 バイトに分解し、指定オフセットから `data[]` に書き込む |
| `read_uint32_le` | リトルエンディアンで読んだ 4 バイトを `uint32_t` に復元する |
| `build_speed_target_command` | 速度目標コマンドペイロード（8 バイト）を構築する |

## 実装のルール

**特に重要：浮動小数点数をバイト列に変換するときは、ポインタキャストではなく `memcpy` を使うこと。**

```c
// NG: 厳密エイリアシング違反（未定義動作）
*(uint32_t*)&f;

// OK: 標準で定義された方法
uint32_t u32;
memcpy(&u32, &f, sizeof(u32));
```

### `write_float_le` の実装

1. `memcpy` で `float` を `uint32_t` に変換する
2. シフト演算と `& 0xFF` で 1 バイトずつ取り出す
3. リトルエンディアンの順序（最下位バイトが先）で `data[]` に書き込む

### `read_float_le` の実装

1. 各バイトを `(uint8_t)` にキャストしてから `widen`（上位ビットに 0 を詰める）して `uint32_t` に組み立てる
2. `memcpy` で `uint32_t` を `float` に変換する
3. `float` を返す

**重要**：`char` は符号付きの処理系が多いので、バイト値を読むときは必ず `(uint8_t)` にキャストしてから、その値を `uint32_t` に widening してください。

### `build_speed_target_command`

部内 CAN プロトコルの**速度目標コマンド**仕様：

- **Byte 0**: ポート ID（1-8、受け取った値をそのまま使う）
- **Byte 1-4**: 目標速度（`float`、LE）
- **Byte 5-7**: 0 埋め

```bash
./drill run c11
```

**未着手のうちはテストが赤くなります。** ヘッダを編集不可にしているので、テストが失敗する形になります。

## つまずきポイント

- **ポインタキャストは厳密エイリアシング違反**です。`memcpy` を使うこと
- **バイト値を読むときは`(uint8_t)`にキャスト**してから widen してください。符号付き `char` でも大丈夫になります
- **往復テスト**で正しさを確認してください。書いた値を読んで、元の値に戻るか確認します
- 仕様は `int8_t`, `int16_t` など固定幅整数型が基本です。可搬性（ポータビリティ）が必要です
