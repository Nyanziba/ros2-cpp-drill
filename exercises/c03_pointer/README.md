# c03: ポインタでアドレスを渡す

C言語のポインタを使い、関数引数経由で変数を書き直す方法を学びます。

## 学習目標

- ポインタの基本的な使用（`&` と `*` 演算子）
- NULL ポインタの確認と安全なチェック
- 値渡しと参照渡し（ポインタ経由）の違い
- 関数による変数の直接的な変更

## 実装すべき関数

1. **`int swap_values(int *a, int *b)`**
   - 2つの変数の値を入れ替える
   - aまたはbがNULLなら-1を返す
   - 成功時は0を返す

2. **`int multiply(int x, int *result)`**
   - xを2倍にしてresultが指す場所に格納
   - resultがNULLなら-1を返す
   - 成功時は0を返す

3. **`int triple_pointer(int *p)`**
   - pが指す値を3倍にする
   - pがNULLなら-1を返す
   - 成功時は0を返す

## ヒント

- ポインタ引数で値を変更するには、`*p = ...` の形で代入
- `NULL` チェックは最初に行う
- 一時変数を使うと値の交換が簡単
