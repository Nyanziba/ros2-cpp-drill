=== ポインタ①（アドレスと間接参照） ===

--- 1. なぜポインタが必要か？---
参照があれば十分では... ない。理由：
  1. null になれる（未初期化状態を表現できる）
  2. 再指向できる（別のオブジェクトに切り替える）
  3. 配列走査（ポインタ演算）ができる

--- 2. アドレスを取る（&） ---
int x = 42;
address of x: &x = 0x7ffffffc0868
size of int: sizeof(int) = 4 bytes

--- 3. ポインタ変数（int *） ---
int * p = &x;
p (アドレス) = 0x7ffffffc0868
*p (間接参照：指す先の値) = 42
sizeof(int*) = 8 bytes (アーキに依存)

--- 4. 間接参照で書き込み ---
*p = 100;
x = 100 (p を通して x が変わった)

--- 5. nullptr チェック ---
int * nullable = nullptr;
nullable = 0 (null ポインタ)
if (nullable) { ... } ではチェック可能
pointer is null

--- 6. null ポインタを逆参照するとクラッシュ ---
警告: 次のコードは実行しません。代わりに説明します
int * bad_ptr = nullptr;
std::cout << *bad_ptr;  // セグメンテーション違反！
実際に実行すると、このプログラムは落ちます

--- 7. ポインタの再指向 ---
int * ptr = &x;  // ptr は x を指す
*ptr = 100
ptr = &y;  // ptr は y を指すようになった
*ptr = 99
x = 100 (変わらない)

--- 8. struct のメンバへのアクセス ---
struct Point { int x, y; };
Point pt{10, 20};
Point * pp = &pt;
(*pp).x = 10
pp->x = 10 (同じ)
pp->y = 20

--- 9. 値・参照・ポインタの比較表 ---
+----------+----------+----------+----------+
| 方式     | null可   | 再指向可 | 値の意味 |
+----------+----------+----------+----------+
| 値       | ×        | N/A      | コピー   |
| 参照     | ×        | ×        | 別名     |
| ポインタ | ○        | ○        | アドレス |
+----------+----------+----------+----------+
