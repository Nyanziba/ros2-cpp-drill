# Three series for student Robocon

- Japanese: https://nyanziba.github.io/ros2-cpp-drill/robocon/index.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/robocon/index.html
- Chinese: https://nyanziba.github.io/ros2-cpp-drill/zh/index.html

These three series assume a three-minute match such as ABU Robocon or NHK Student Robocon. The existing C, C++, ROS 2, and design-pattern chapters stay as they are. Code and tests are shared. Only the reading and the exercise text are split by language.

## Series

| Series | Exercises | What it covers |
| --- | --- | --- |
| Vision | `cv01` to `cv06` | color, ONNX, dataset, speed, node, gaze |
| Behavior trees | `bt01` to `bt03` | priority, actions, avoidance |
| Autonomy | `nav01` to `nav03` | yaw, state, routes |
