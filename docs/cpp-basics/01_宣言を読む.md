# 1. 宣言を読む

> **この章のねらい**: C++ の変数宣言には型の前後に装飾が付きます。`const int * const p` のような並びを見ると「これは何？」と思い、ドリルが進まないという状態があります。
> この章では、**変数名を起点に右から左に読む手順**を学びます。この手順は暗記ではなく機械的な手続きなので、何度でも使えます。
> 課題 01 のコード読解に必須です。

## 1.1 宣言を右から左に読む

C++ の宣言を左から読もうとすると分かりません。**右から左に読みます。**
これは好みではなく、C++ の宣言構文がそう組まれているからです。

### 手順

1. **変数名を見つける**
2. **そこから左へ 1 トークンずつ読む**
3. **記号をそのつど日本語に置き換える**

置き換え表はこれだけです。

| 記号 | 読み |
| --- | --- |
| `&` | 〜への参照 |
| `*` | 〜へのポインタ |
| `const` | 変更できない |
| 型名 | その型 |

### 例

**例 1: `int x`**

```
int   x
 ②    ①
```

① `x` は → ② `int`。**「x は int」**

**例 2: `int * p`**

```
int   *   p
 ③    ②   ①
```

① `p` は → ② ポインタで → ③ その先は `int`。**「p は int へのポインタ」**

**例 3: `const int * q`**

```
const  int   *   q
  ④     ③    ②   ①
```

① `q` は → ② ポインタで → ③④ その先は「変更できない int」。
**「q は 変更できない int へのポインタ」**

ここが肝心です。**`const` は左端にありますが、`q` に付いているのではなく `int` に付いています。**
「ポインタそのものが const」ではなく「ポインタが指す先が const」です。

**例 4: `int * const r`**

```
int   *   const   r
 ④    ③     ②      ①
```

① `r` は → ② 変更できない → ③ ポインタで → ④ その先は `int`。
**`const` が `*` の右にあるので、「ポインタ自身が const」**です。
再指向できない、という意味です。

### const の法則

**`const` は「自分のすぐ左にあるもの」に付く。左に何も無ければ、右のものに付く。**

| パターン | 左が何か | 結果 |
| --- | --- | --- |
| `const int *` | `const` の左は何も無い | 右の `int` に付く → 指す先が const |
| `int const *` | `const` の左は `int` | `int` に付く → 指す先が const（同じ） |
| `int * const` | `const` の左は `*` | `*`（ポインタ）に付く → ポインタが const |
| `const int * const` | 最初の `const` は `int` に、次の `const` は `*` に付く | 両方 const |

だから `const int *` と `int const *` は**同じ意味**です。

## 1.2 全パターン表

ここまでの手順で、出てくるすべての組み合わせを読めます。

| 宣言 | 読み方 | できることと できないこと |
| --- | --- | --- |
| `int x` | x は int | 読める・書ける |
| `const int x` | x は 変更できない int | 読めるが書けない |
| `int & x` | x は int への参照 | 元のものを読める・書ける |
| `const int & x` | x は 変更できない int への参照 | 元のものを読めるが書けない |
| `int * x` | x は int へのポインタ | `*x` で読める・書ける。`x` を差し替えられる |
| `const int * x` | x は 変更できない int へのポインタ | `*x` は読めるが書けない。`x` は差し替えられる |
| `int * const x` | x は 変更できない「int へのポインタ」 | `*x` は書ける。`x` は差し替えられない |
| `const int * const x` | x は 変更できない「変更できない int へのポインタ」 | どちらも不可 |

## 1.3 メンバ関数の const（この手順の例外）

**メンバ関数の末尾に付く `const` だけは、この手順の対象外です。**

```cpp
void topic_callback(const std_msgs::msg::String & msg) const
//                                                     ^^^^^ これ
```

これは**変数の宣言ではなく、関数の宣言**です。
「この関数はオブジェクトを変更しない」という意味で、6 章で扱います。

見分け方は簡単です。**`)` の後ろにある `const` は、必ずメンバ関数の `const`。**
それ以外の `const` は上の手順で読めます。

## 1.4 練習

次の 6 つを、手順どおり右から左に読んでください。声に出すか、紙に書いてください。

```cpp
double v
const double & v
char * argv[]
const rclcpp::NodeOptions & options
std::shared_ptr<Node> node
const std::shared_ptr<Request> request
```

答えは順に

1. `v` は double
2. `v` は 変更できない double への参照
3. `argv` は 「char へのポインタ」の配列（課題 01 の `main` の引数）
4. `options` は 変更できない `rclcpp::NodeOptions` への参照
5. `node` は `std::shared_ptr<Node>`（`<>` の中はまとめて 1 個の型）
6. `request` は 変更できない `std::shared_ptr<Request>`。参照ではなく**値**です（`&` が無い）

**6 番に引っかかったら、それは正しい引っかかり方です。**
`&` が無ければ参照ではありません。`const` があるからといって参照とは限りません。
2 つは独立した修飾です。

## 手元で試す

**宣言をいくつか読んで、実際に動かして確認します。**

```cpp
// basics01_practice.cpp
#include <iostream>
#include <vector>

int main()
{
  std::cout << "=== 宣言を読む練習 ===\n\n";

  // パターン 1: int x
  int x = 10;
  std::cout << "1. int x\n";
  std::cout << "   読み方: x は int\n";
  std::cout << "   x = " << x << "\n\n";

  // パターン 2: int * p
  int * p = &x;
  std::cout << "2. int * p = &x\n";
  std::cout << "   読み方: p は int へのポインタ\n";
  std::cout << "   p (アドレス) = " << p << "\n";
  std::cout << "   *p (指す先) = " << *p << "\n";
  *p = 20;
  std::cout << "   *p = 20; で x も変わった: " << x << "\n\n";

  // パターン 3: const int * q
  int const_val = 100;
  const int * q = &const_val;
  std::cout << "3. const int * q\n";
  std::cout << "   読み方: q は (変更できない int) へのポインタ\n";
  std::cout << "   q (アドレス) = " << q << "\n";
  std::cout << "   *q (指す先、読むだけ) = " << *q << "\n";
  std::cout << "   試験: エラーになるはずなので行を消しています\n";
  std::cout << "   // *q = 99;   ← できない\n\n";

  // パターン 4: int * const r
  int val = 50;
  int * const r = &val;
  std::cout << "4. int * const r = &val\n";
  std::cout << "   読み方: r は 変更できない (int へのポインタ)\n";
  std::cout << "   r (アドレス) = " << r << "\n";
  std::cout << "   *r (指す先) = " << *r << "\n";
  *r = 60;
  std::cout << "   *r = 60; で val も変わった: " << val << "\n";
  std::cout << "   試験: r 自身は再指向できません\n";
  std::cout << "   // r = &x;   ← できない\n\n";

  // パターン 5: const int * const s
  int val2 = 200;
  const int * const s = &val2;
  std::cout << "5. const int * const s = &val2\n";
  std::cout << "   読み方: s は 変更できない (変更できない int へのポインタ)\n";
  std::cout << "   s (アドレス) = " << s << "\n";
  std::cout << "   *s (指す先、読むだけ) = " << *s << "\n";
  std::cout << "   試験: 両方できません\n";
  std::cout << "   // *s = 99;   ← できない (指す先が const)\n";
  std::cout << "   // s = &x;    ← できない (ポインタが const)\n\n";

  // const の左右の法則を確認
  std::cout << "=== const の左右の法則 ===\n\n";
  std::cout << "const int * と int const * は同じ意味\n";
  std::cout << "  const int * a = &const_val;    // 指す先が const\n";
  std::cout << "  int const * b = &const_val;    // 指す先が const\n";
  std::cout << "  結果: 両方とも指す先を変更できない\n\n";

  std::cout << "int * const はポインタ自身が const\n";
  std::cout << "  int * const c = &val;\n";
  std::cout << "  結果: ポインタ自身を再指向できない\n\n";

  // 配列への参照パターン
  std::cout << "=== 応用: ポインタの配列 ===\n\n";
  int v1 = 1, v2 = 2, v3 = 3;
  int * array[] = {&v1, &v2, &v3};
  std::cout << "int * array[] = {&v1, &v2, &v3};\n";
  std::cout << "読み方: array は (int へのポインタ) の配列\n";
  for (int i = 0; i < 3; ++i) {
    std::cout << "  array[" << i << "] = " << array[i] << " -> *array[" << i << "] = " << *array[i] << "\n";
  }

  return 0;
}
```

## つまずきポイント

**「const はどこに付くのか」で悩む**

右から左に読む手順に従うと、自動的に分かります。迷ったら手順をもう一度なぞってください。

**`const int *` と `int const *` は本当に同じ？**

はい、完全に同じです。`const` の法則「左にあるものに付く。左に何も無ければ右に付く」から、両方 `int` に付きます。

**「int へのポインタ」と「参照」がまだ混同している**

これは正常です。3 章 で参照、4 章でポインタを詳しく扱います。今は「`*` が付いたらポインタ」「`&` が付いたら参照」くらいに思ってください。
