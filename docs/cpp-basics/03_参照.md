# 3. 参照

> **この章のねらい**: `int & x` という宣言を見ると、「これは何？ ポインタと何が違うのか」と感じます。
> そもそも `&` という記号は、型を修飾するときと式の中での動作が全く違う意味で使われています。
> 位置で意味が変わるという、この混乱を明確に解きます。
> 参照は 4〜5 章・6 章・8 章での比較対象になるので、ここで曖昧にしてはいけません。

## 3.1 参照とは別名

`int & ref = x;` は「ref は x の別名」という意味です。同じオブジェクトの 2 つの名前を持つと考えてください。

```cpp
int x = 10;
int & ref = x;

ref = 20;
std::cout << x;  // 20（ref を通して変更したが、x も変わった）
```

参照を通して値を変更すれば、元のオブジェクトが変わります。これは**コピーではなく別名**だからです。

## 3.2 重要：`&` の 2 つの使い方

**`int & x` （宣言）と `&x` （式）の `&` は、同じ記号ですが意味が全く違います。**

| 文脈 | 意味 | 例 |
| --- | --- | --- |
| 型の修飾（宣言） | 参照（別名） | `int & ref = x;` |
| 式の演算子 | アドレス取得（ポインタ化） | `int * p = &x;` |

**位置で判別します。** 型の修飾ならば参照、式の中ならばアドレス取得です。

## 3.3 参照は初期化必須

参照は宣言時に初期化が必須です。未初期化の参照は存在できません。

```cpp
int & r;        // エラー：初期化が無い
int & r = x;    // OK
```

コンパイラメッセージ:
```
error: declaration of reference variable 'r' requires an initializer
```

## 3.4 参照は再束縛できない

参照を作ったあと、別のオブジェクトを指すように変更できません。

```cpp
int x = 1, y = 2;
int & ref = x;
ref = y;  // ref が y を指すようになった？
```

**いいえ。`ref = y;` は「ref を y に再束縛する」ではなく「ref を通して x に y の値を代入する」という意味です。**

```cpp
std::cout << x;    // 2（y の値が入っている）
std::cout << ref;  // 2（ref は相変わらず x の別名）
```

ref は常に x の別名のままです。

## 3.5 参照は null にできない

参照は常に何らかのオブジェクトを指さなければなりません。null にすることはできません。

```cpp
int & ref = nullptr;  // エラー
```

コンパイラメッセージ:
```
error: a reference of type 'int&' cannot bind to a null pointer
```

「何かが存在しない」という状態を表現したい場合は、ポインタ（4 章）を使います。

## 3.6 参照渡し

関数に参照で渡すと、呼び出し側の変数を関数内で直接変更できます。

```cpp
void modify(int & x) {
  x = 99;
}

int a = 1;
modify(a);
std::cout << a;  // 99（modify の中で a が変わった）
```

これは**値渡し**（コピー）との大きな違いです。

| 値渡し | 参照渡し |
| --- | --- |
| `void f(int x)` | `void f(int & x)` |
| コピーを受け取る | 元のオブジェクトを受け取る |
| 関数内の変更は呼び出し側に反映されない | 関数内の変更が呼び出し側に反映される |
| 呼び出し側の書き方は `f(a)` | 呼び出し側の書き方は `f(a)`（同じ） |

## 3.7 const 参照（読み取り専用の別名）

`const int & ref` は、参照先を変更できない参照です。

```cpp
int x = 100;
const int & const_ref = x;

std::cout << const_ref;  // 読める
const_ref = 200;         // エラー：const なので書けない
```

一時値（リテラル）を `const` 参照で受け取ることもできます。

```cpp
const int & temp = 42;
std::cout << temp;  // 42
```

非 const 参照は一時値を受け取れません。

```cpp
int & non_const_ref = 42;  // エラー
```

## 3.8 ダングリング参照

関数から参照を返すと、その参照先が関数を抜けたあとに破棄される危険があります。

```cpp
const int & bad_function(int x) {
  int local = x + 1;
  return local;  // local は関数を抜けると破棄される
}

const int & ref = bad_function(5);  // ref は無効（ダングリング参照）
std::cout << *ref;                  // undefined behavior
```

コンパイラが警告を出すはずです：

```
warning: returning reference to local variable [-Wreturn-local-addr]
```

参照を返すなら、渡された参照を返すか、オブジェクトが関数を抜けても存在することを保証してください。

## 手元で試す

**参照の動作を 9 つのパターンで確認します。**

```cpp
// basics03_practice.cpp
#include <iostream>

int main()
{
  std::cout << "=== 参照 ===\n\n";

  std::cout << "--- 1. 参照は別名 ---\n";
  int x = 10;
  int & ref = x;
  std::cout << "int x = 10;\n";
  std::cout << "int & ref = x;\n";
  std::cout << "x = " << x << "\n";
  std::cout << "ref = " << ref << "\n";
  std::cout << "&x = " << &x << "\n";
  std::cout << "&ref = " << &ref << " (同じアドレス！)\n\n";

  std::cout << "--- 2. 参照を通して変更 ---\n";
  ref = 20;
  std::cout << "ref = 20; で x も変わった\n";
  std::cout << "x = " << x << "\n";
  std::cout << "ref = " << ref << "\n\n";

  std::cout << "--- 3. 参照は初期化必須 ---\n";
  std::cout << "試験: int & r; (初期化なし) はエラー\n";
  std::cout << "error: declaration of reference variable 'r' requires an initializer\n";
  std::cout << "（実際に試してみてください）\n\n";

  std::cout << "--- 4. 参照は再束縛できない ---\n";
  int y = 30;
  int & ref2 = x;
  std::cout << "int y = 30;\n";
  std::cout << "int & ref2 = x;  // ref2 は x を指す\n";
  std::cout << "ref2 = y;  // これは y の『値』を x に代入！\n";
  ref2 = y;
  std::cout << "結果: x = " << x << " (y の値 30 が入った)\n";
  std::cout << "     y = " << y << " (そのまま)\n";
  std::cout << "ref2 は相変わらず x の別名です\n\n";

  std::cout << "--- 5. 参照は null にできない ---\n";
  std::cout << "参照は必ず何らかのオブジェクトを指す\n";
  std::cout << "int & null_ref = nullptr;  // これはエラー\n";
  std::cout << "error: a reference of type 'int&' cannot bind to a null pointer\n\n";

  std::cout << "--- 6. 値渡しと参照渡しの違い ---\n";
  auto modify_by_value = [](int n) {
    n = 999;
  };
  auto modify_by_ref = [](int & n) {
    n = 999;
  };

  int a = 1, b = 1;
  std::cout << "before modify_by_value: a = " << a << "\n";
  modify_by_value(a);
  std::cout << "after modify_by_value:  a = " << a << " (変わらない)\n\n";

  std::cout << "before modify_by_ref:  b = " << b << "\n";
  modify_by_ref(b);
  std::cout << "after modify_by_ref:   b = " << b << " (変わった！)\n\n";

  std::cout << "--- 7. const 参照（読み取り専用の別名） ---\n";
  int original = 100;
  const int & const_ref = original;
  std::cout << "const int & const_ref = original;\n";
  std::cout << "const_ref = " << const_ref << "\n";
  std::cout << "const_ref = 999;  // エラー（const）\n";
  std::cout << "original = 200;  // OK（const_ref 経由ではなく直接）\n";
  original = 200;
  std::cout << "const_ref = " << const_ref << " (original の変化を見る)\n\n";

  std::cout << "--- 8. 一時値への const 参照 ---\n";
  const int & temp_ref = 42;
  std::cout << "const int & temp_ref = 42;\n";
  std::cout << "temp_ref = " << temp_ref << "\n";
  std::cout << "一時値は const 参照なら生きている\n";
  std::cout << "（非 const 参照だとエラー）\n\n";

  std::cout << "--- 9. 関数から参照を返す（ダングリングの危険） ---\n";
  std::cout << "試験: 次のコードはダングリング参照を作る\n";
  std::cout << "const int & dangerous_ref = [](const int & x) -> const int & {\n";
  std::cout << "  int local = x + 1;\n";
  std::cout << "  return local;  // local は関数を抜けると破棄される！\n";
  std::cout << "} (original);\n";
  std::cout << "コンパイラが警告するはずです\n";
  std::cout << "warning: returning reference to local variable\n";

  return 0;
}
```

## つまずきポイント

**「参照と値渡しの違いが分からない」**

参照渡しは、呼び出し側の変数そのものを関数に渡します。関数内での変更が元の変数に反映されます。
値渡しはコピーを渡すので、関数内での変更は元の変数に反映されません。
6 番の出力を見れば一目瞭然です。

**「参照を再束縛できない」という説明が曖昧に感じる**

`int & ref = x; ref = y;` は「ref を y に再束縛」ではなく「ref を通して x に y の値を代入」という 2 段階の意味に分かれます。
`ref` は常に `x` の別名です。再束縛は**できません**。

**「const 参照は何のためにあるのか」**

読み取り専用の借用です。関数のパラメータで頻繁に使われます。
大きなオブジェクトをコピーせずに、読み取り専用で借りるという意図を表現できます。
これは 8 章の詳しい説明までのプレビューです。
