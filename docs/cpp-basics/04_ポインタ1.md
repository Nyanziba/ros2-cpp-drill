# 4. ポインタ①（アドレスと間接参照）

> **この章のねらい**: 参照があれば十分に見えるのに、なぜポインタが必要なのか。その理由は 3 つです。
> **null になれる**（オプショナルを表現できる）、**再指向できる**（別のオブジェクトに切り替える）、**ポインタ演算ができる**（配列走査）。
> これらが実務でなぜ重要なのかを具体的に示します。

## 4.1 なぜポインタが必要か

参照（3 章）はシンプルで安全ですが、3 つの点で制限があります。

| 要件 | 参照 | ポインタ | 用途例 |
| --- | --- | --- | --- |
| null を表現したい | ✗ | ✓ | 検索結果が「見つからない」を表現 |
| 同じ変数を複数の値に指し替えたい | ✗ | ✓ | リスト走査での次のノードへ移動 |
| アドレスを演算したい | ✗ | ✓ | 配列の要素を順に処理 |

参照では不可能な 3 つの要件が出てくるたびに、ポインタが活躍します。

### 例：検索関数

```cpp
// 参照では書けない（見つからない場合を表現できない）
int & search(int * arr, int size, int target);

// ポインタなら可能（nullptr で「見つからない」を表現）
int * search(int * arr, int size, int target) {
  for (int i = 0; i < size; ++i) {
    if (arr[i] == target) return &arr[i];
  }
  return nullptr;  // 見つかりませんでした
}
```

## 4.2 アドレスを取得する（`&`）

`&x` で変数 `x` のアドレス（メモリ上の住所）を得ます。

```cpp
int x = 42;
std::cout << &x;  // 0x7fff5fbff8ac （アドレスは実行ごとに異なる）
```

このアドレスを変数に保存するのがポインタです。

## 4.3 ポインタ変数（`int *`）

ポインタは「アドレス」を格納する変数です。

```cpp
int x = 42;
int * p = &x;      // p は x のアドレスを格納

std::cout << p;    // 0x...（アドレス）
std::cout << *p;   // 42（指す先の値）
```

- `p` ：ポインタそのもの（アドレス）
- `*p` ：ポインタが指す先の値（間接参照）

## 4.4 間接参照で値を変更

ポインタを通して指す先の値を変更できます。

```cpp
int x = 10;
int * p = &x;
*p = 100;
std::cout << x;  // 100（p を通して x が変わった）
```

これは参照と同じ効果です。異なるのは、ポインタは再指向できることです。

## 4.5 nullptr：null ポインタ

ポインタは `nullptr`（null ポインタ）で「何も指していない」を表現します。

```cpp
int * p = nullptr;

if (p) {
  std::cout << *p;  // null でなければ安全に逆参照
} else {
  std::cout << "pointer is null";  // null なら処理をスキップ
}
```

この**null チェック**により、オプショナルな値を表現できます。

## 4.6 null ポインタを逆参照するとクラッシュ

null ポインタを逆参照すると、プログラムがクラッシュします（セグメンテーション違反）。

```cpp
// segv.cpp
#include <iostream>

int main()
{
  int * bad_ptr = nullptr;
  std::cout << *bad_ptr << "\n";   // セグメンテーション違反
  return 0;
}
```

**一度だけ実際に落としてみてください。** 症状を知らないと、実機で遭ったときに気付けません。

```bash
$ g++ -std=c++17 segv.cpp -o segv
$ ./segv
Segmentation fault (コアダンプ)
$ echo $?
139
```

[▶ ブラウザで実行する（gcc 13.3）](https://godbolt.org/z/rrcYazfzG)

**コンパイルは通ります。警告も出ません。** 落ちるのは実行時です。
終了コード 139 は `128 + 11`（SIGSEGV）を意味します。
シェルスクリプトや CI でこの数字を見たら、null 参照外しか範囲外アクセスを疑ってください。

**ポインタを逆参照する前に、必ず null チェックしてください。**
これは参照（3章）には無い手間です。「null になれる」ことの代償がこれです。

## 4.7 ポインタの再指向

参照と異なり、ポインタは別のオブジェクトを指すように変更できます。

```cpp
int x = 10, y = 20;
int * ptr = &x;
std::cout << *ptr;  // 10

ptr = &y;           // ptr が y を指すようになった
std::cout << *ptr;  // 20
```

リンクリストなど、次のノードに移動する処理で必須です。

## 4.8 struct のメンバアクセス

ポインタを通して struct のメンバにアクセスするには 2 つの書き方があります。

```cpp
struct Point { int x, y; };
Point p{10, 20};
Point * pp = &p;

std::cout << (*pp).x;  // 10（先に逆参照、その後メンバアクセス）
std::cout << pp->x;    // 10（ポインタメンバアクセス演算子）
```

2 つは同じ意味です。**`->` は `(*p).` の短記法**です。

## 4.9 値・参照・ポインタの比較

| 特性 | 値 | 参照 | ポインタ |
| --- | --- | --- | --- |
| コピーが起きるか | ✓ はい | ✗ いいえ | ✗ いいえ |
| null になれるか | N/A（値そのもの） | ✗ 不可 | ✓ 可能 |
| 再指向できるか | N/A（代入すれば別の値） | ✗ 不可 | ✓ 可能 |
| 呼び出し側の書き方 | `f(a)` | `f(a)` | `f(p)` または `f(&a)` |

## 手元で試す

**ポインタの基本を 9 つのパターンで確認します。**

```cpp
// basics04_practice.cpp
#include <iostream>

int main()
{
  std::cout << "=== ポインタ①（アドレスと間接参照） ===\n\n";

  std::cout << "--- 1. なぜポインタが必要か？---\n";
  std::cout << "参照があれば十分では... ない。理由：\n";
  std::cout << "  1. null になれる（未初期化状態を表現できる）\n";
  std::cout << "  2. 再指向できる（別のオブジェクトに切り替える）\n";
  std::cout << "  3. 配列走査（ポインタ演算）ができる\n\n";

  std::cout << "--- 2. アドレスを取る（&） ---\n";
  int x = 42;
  std::cout << "int x = 42;\n";
  std::cout << "address of x: &x = " << &x << "\n";
  std::cout << "size of int: sizeof(int) = " << sizeof(int) << " bytes\n\n";

  std::cout << "--- 3. ポインタ変数（int *） ---\n";
  int * p = &x;
  std::cout << "int * p = &x;\n";
  std::cout << "p (アドレス) = " << p << "\n";
  std::cout << "*p (間接参照：指す先の値) = " << *p << "\n";
  std::cout << "sizeof(int*) = " << sizeof(int*) << " bytes (アーキに依存)\n\n";

  std::cout << "--- 4. 間接参照で書き込み ---\n";
  *p = 100;
  std::cout << "*p = 100;\n";
  std::cout << "x = " << x << " (p を通して x が変わった)\n\n";

  std::cout << "--- 5. nullptr チェック ---\n";
  int * nullable = nullptr;
  std::cout << "int * nullable = nullptr;\n";
  std::cout << "nullable = " << nullable << " (null ポインタ)\n";
  std::cout << "if (nullable) { ... } ではチェック可能\n";
  if (nullable) {
    std::cout << "pointer is valid\n";
  } else {
    std::cout << "pointer is null\n";
  }
  std::cout << "\n";

  std::cout << "--- 6. null ポインタを逆参照するとクラッシュ ---\n";
  std::cout << "警告: 次のコードは実行しません。代わりに説明します\n";

  std::cout << "std::cout << *bad_ptr;  // セグメンテーション違反！\n";
  std::cout << "実際に実行すると、このプログラムは落ちます\n\n";

  std::cout << "--- 7. ポインタの再指向 ---\n";
  int y = 99;
  int * ptr = &x;
  std::cout << "int * ptr = &x;  // ptr は x を指す\n";

  ptr = &y;
  std::cout << "ptr = &y;  // ptr は y を指すようになった\n";
  std::cout << "*ptr = " << *ptr << "\n";
  std::cout << "x = " << x << " (変わらない)\n\n";

  std::cout << "--- 8. struct のメンバへのアクセス ---\n";
  struct Point {
    int x, y;
  };
  Point pt{10, 20};
  Point * pp = &pt;
  std::cout << "struct Point { int x, y; };\n";
  std::cout << "Point pt{10, 20};\n";
  std::cout << "Point * pp = &pt;\n";
  std::cout << "(*pp).x = " << (*pp).x << "\n";
  std::cout << "pp->x = " << pp->x << " (同じ)\n";
  std::cout << "pp->y = " << pp->y << "\n\n";

  std::cout << "--- 9. 値・参照・ポインタの比較表 ---\n";

  std::cout << "| ポインタ | ○        | ○        | アドレス |\n";
  std::cout << "+----------+----------+----------+----------+\n";

  return 0;
}
```

## つまずきポイント

**「ポインタと参照の違いがまだ曖昧」**

参照は「別名」で、常に何かを指す。ポインタは「アドレスを格納する変数」で、null になったり再指向できたりします。
4 番・5 番の出力を見比べると、その違いが明確になります。

**「-> と (*p). の違いが分からない」**

`pp->x` は `(*pp).x` の短記法です。同じ意味です。
実務では `pp->x` がよく使われますが、どちらでもかまいません。

**「アドレスが大きな 16 進数なのはなぜ」**

メモリアドレスは実行環境（OS、マシン、実行タイミング）ごとに異なります。
16 進数で表記されるのは慣例です。値自体は重要ではなく、「別々なら独立した変数」「同じなら同じ変数」と読むだけで十分です。
