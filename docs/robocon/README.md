# 学生ロボコン向けの3シリーズ

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/robocon/index.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/robocon/index.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/index.html

ここから先は、ABU ロボコン / NHK 学生ロボコンのような3分の試合を想定したシリーズです。既存の C、C++、ROS 2、デザインパターンの章はそのままです。コードとテストは3言語で共通で、読み物と課題文だけが分かれています。

## シリーズ

| シリーズ | 課題 | 内容 |
| --- | --- | --- |
| 画像処理 | `cv01`〜`cv06` | 色、ONNX、データセット、速度、ノード、視線 |
| ビヘイビアツリー | `bt01`〜`bt03` | 優先順位、アクション、回避 |
| 自律制御 | `nav01`〜`nav03` | ヨー、状態、経路 |

## 言語

- [画像処理編](../vision/README.md)
- [ビヘイビアツリー編](../behavior-tree/README.md)
- [自律制御編](../autonomy/README.md)

## 進め方

```bash
./drill run cv01
```
