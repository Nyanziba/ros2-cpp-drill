# 3. 回避

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/behavior-tree/03_回避.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/behavior-tree/03_avoidance.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/behavior-tree/03_avoidance.html

前方の障害物は、得点より先に処理します。ただし接触する距離まで近づいたら、避けるより先に止まります。この章は、その規則を普通の関数とビヘイビアツリーの両方で書き、両方が同じコマンドになることをテストします。

## 規則

front が 150 mm 未満なら Stop です。それ以外で 400 mm 未満なら、より開いている側へ避けます。左右が同じなら左です。障害物が無く、ゴールが見えていれば Go、見えなければ Search です。

| 項目 | 決まり |
| --- | --- |
| 木が書く文字列 | stop, left, right, go, search |
| XML | Fallback と Sequence を含める |

## 関数と木

`decide_avoidance` が基準です。木は黒板の front_mm、left_mm、right_mm、goal_visible を読んで、command に同じ結果を書きます。規則を2箇所に書き写すので、片方だけ直して食い違わせないでください。

```cpp
AvoidCommand command = decide_avoidance(front_mm, left_mm, right_mm, goal_visible);
// tree writes command: stop, left, right, go, search
```
