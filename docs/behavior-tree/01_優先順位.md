試合中の判断は、全部を if で並べると、緊急停止を後から差し込みにくくなります。ビヘイビアツリーは「先に成功した枝を採用する」Fallback で優先順位を表します。この章は BehaviorTree.CPP v4 です。

## 上から順に

非常停止は制限時間より先です。制限時間は、残りの探索や得点より先で、このときは木全体が FAILURE になり、trace は空のままです。その分岐は TimeUp を Inverter で包みます。距離 400 mm 未満は回避、マーカーが見えていれば得点、それ以外は探索です。400 mm ちょうどは障害物ではありません。

| 項目 | 決まり |
| --- | --- |
| estop | trace は estop。time_up が同時でもこちら |
| time_up | FAILURE。trace は空。Inverter で包む |

## ノードの種類

Sequence は子が全部成功するまで進みます。Fallback は子が1つ成功すれば成功です。Condition は SUCCESS か FAILURE だけを返し、RUNNING にしません。Action が黒板の `trace` にラベルを足します。

```cpp
register_match_nodes(factory);
auto tree = factory.createTreeFromText(match_xml());
tree.tickOnce();
```

## CI でやらないこと

ロボットは動かしません。1 回の `tickOnce` のあと、黒板の文字列だけを見ます。
