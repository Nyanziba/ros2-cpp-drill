# 2. アクションと黒板

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/behavior-tree/02_アクションと黒板.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/behavior-tree/02_actions_and_blackboard.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/behavior-tree/02_actions_and_blackboard.html

ゾーンまで走る処理は、1 tick では終わりません。BehaviorTree.CPP の `StatefulActionNode` は onStart、onRunning、onHalted の3つで、ROS 2 アクションの「送った、まだ走っている、中断した」に対応します。実物のアクションサーバは立てず、同じ状態番号を返すクライアントを差し込みます。

## ゴール

残り時間が 0.5 秒未満なら zone は `abort`、timeout は 0 で、送りません。それ以外の timeout は `min(3.0, time_left)` です。action の状態番号は、EXECUTING(2) と CANCELING(3) が RUNNING、SUCCEEDED(4) が SUCCESS、それ以外が FAILURE です。

| 項目 | 決まり |
| --- | --- |
| 黒板 | drive_client、time_left、ポート zone |
| onHalted | RUNNING のまま halt されたら cancel する |

## 本物のクライアント

ロボットに載せるときは `rclcpp_action` のクライアントが `DriveClient` の役をします。send、cancel、status の3つだけをインターフェースにしたので、テストはサーバもエグゼキュータも要りません。

```cpp
DriveGoal goal = make_drive_goal(zone, time_left_sec);
BT::NodeStatus status = status_from_action(code);
```

## CI でやらないこと

アクションサーバは起動しません。FakeDrive が状態番号を返すだけです。
