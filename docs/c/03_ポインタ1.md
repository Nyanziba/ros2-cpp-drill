# 3. ポインタ① — アドレスと間接参照

> **この章のねらい**: ポインタは「メモリのアドレスを格納する変数」です。`&`（アドレス取得）と `*`（間接参照）の 2 つの演算子で、変数のアドレスを読み書きし、そのアドレスを経由して値を変更できます。値渡しでは呼び出し側が変わらないのに対し、ポインタを渡すと関数から呼び出し側の変数を書き換えられます。この仕組みを理解することで、C の制御の流れが見通しよくなります。

## 3.1 アドレスと参照 — `&` と `*`

**`&` — アドレス取得演算子**

変数のメモリアドレスを得ます。

```c
int x = 42;
int *p = &x;  // p はアドレスを持つ
```

`&x` は「x が格納されているメモリアドレス」です。

**`*` — 間接参照演算子（dereference）**

ポインタが指すアドレスの値を読み書きします。

```c
int *p = &x;
printf("%d\n", *p);  // x と同じ値
*p = 100;            // x も 100 に変わる
```

`*p` は「p が指しているメモリの値」です。

## 3.2 ポインタ変数の宣言

**型の後に `*` を付ける。**

```c
int *p;       // int へのポインタ
double *q;    // double へのポインタ
int **pp;     // int へのポインタへのポインタ（ポインタ二重）
```

`*` の位置は「その変数がポインタ」という意味です。

## 3.3 NULL — ポインタが指さないアドレス

**`NULL` は「何も指していない」という特殊な値**

```c
int *p = NULL;
if (p == NULL) {
  printf("pointer is NULL\n");
}
```

関数から戻り値のポインタが「失敗」を意味する場合、`NULL` を返すことがあります。

```c
int *allocate(int size)
{
  if (size <= 0) {
    return NULL;  // 失敗
  }
  // ...
}
```

使う側は必ずチェックしてください。

```c
int *p = allocate(10);
if (p == NULL) {
  printf("allocation failed\n");
  return;
}
```

`NULL` を指すポインタに対して `*p` をすると、**セグメンテーション違反**になります。

## 3.4 値渡し — 呼び出し側は変わらない

関数に値を渡すと、**コピーが関数に渡される**。

```c
void increment(int x)
{
  x++;  // ローカル変数 x を変更
}

int main()
{
  int n = 10;
  increment(n);
  printf("%d\n", n);  // 10 のまま（変わらない）
}
```

関数内で `x` を変更しても、呼び出し側の `n` は変わりません。

## 3.5 ポインタ渡し — 呼び出し側を書き換える

関数にポインタを渡すと、**アドレスを経由して元の変数を書き換える**。

```c
void increment(int *p)
{
  (*p)++;  // p が指す変数を変更
}

int main()
{
  int n = 10;
  increment(&n);
  printf("%d\n", n);  // 11（変わった）
}
```

`increment(&n)` で `n` のアドレスを渡し、関数内で `*p` を変更すると、`n` が変わります。

**括弧に注意：**

```c
(*p)++;   // p が指す値に 1 を足す（正しい）
*p++;     // p を 1 進める（ポインタが動く）
```

後者は「ポインタを次のアドレスに進める」という意味になります。

## 3.6 `const` とポインタ

**`const int *p` — 指す先が `const`**

```c
const int *p = &x;
*p = 100;  // エラー（指す先を書き換えられない）
p = &y;    // OK（ポインタは動かせる）
```

「`int` 定数へのポインタ」と読みます。

**`int * const p` — ポインタが `const`**

```c
int * const p = &x;
*p = 100;  // OK（指す先を書き換えられる）
p = &y;    // エラー（ポインタは動かせない）
```

「定数な `int` ポインタ」と読みます。

**覚え方：`const` の左側を読む。**

- `const int *` — `const` の左は `int` → `int` が `const`
- `int * const` — `const` の左は `*` → ポインタが `const`

## 手元で試す

ポインタの基本、値渡しとポインタ渡しの違い、`const` ポインタを確認します。

### 例 1：アドレスと間接参照

**予想**: `p` が `x` と同じ値を指すか。`*p = 100` で `x` も変わるか。

```c
// ch03_ptr_handson.c
#include <stdio.h>

void increment_by_value(int x)
{
  x++;
}

void increment_by_pointer(int *p)
{
  (*p)++;
}

int main()
{
  printf("== Passing by value ==\n");
  int x = 10;
  printf("Before: x = %d\n", x);
  increment_by_value(x);
  printf("After increment_by_value(x): x = %d\n", x);

  printf("\n== Passing by pointer ==\n");
  int y = 10;
  printf("Before: y = %d\n", y);
  increment_by_pointer(&y);
  printf("After increment_by_pointer(&y): y = %d\n", y);

  printf("\n== Pointer to pointer ==\n");
  int value = 42;
  int *p = &value;
  int **pp = &p;

  printf("value = %d\n", value);
  printf("*p = %d\n", *p);
  printf("**pp = %d\n", **pp);

  printf("\n== const pointer ==\n");
  int a = 100;
  int b = 200;

  const int *cp = &a;  // pointer to const int
  printf("const int *cp = &a: %d\n", *cp);
  cp = &b;  // OK - can move pointer
  printf("After cp = &b: %d\n", *cp);

  int * const p_const = &a;  // const pointer to int
  printf("int * const p_const = &a: %d\n", *p_const);
  *p_const = 150;  // OK - can modify pointee
  printf("After *p_const = 150: a = %d\n", a);

  return 0;
}
```

コンパイル・実行：

```bash
gcc -std=c99 -Wall -Wextra -Wpedantic ch03_ptr_handson.c -o ch03_ptr_handson && ./ch03_ptr_handson
```

出力：

<details markdown="1"><summary>解答（実行結果）</summary>

```
== Passing by value ==
Before: x = 10
After increment_by_value(x): x = 10

== Passing by pointer ==
Before: y = 10
After increment_by_pointer(&y): y = 11

== Pointer to pointer ==
value = 42
*p = 42
**pp = 42

== const pointer ==
const int *cp = &a: 100
After cp = &b: 200
int * const p_const = &a: 100
After *p_const = 150: a = 100
```

</details>

3 点確認してください。

<details markdown="1"><summary>解答（答え合わせ）</summary>

1. **値渡し** — 関数から戻ると `x` は 10 のまま（コピーが渡されたから）
2. **ポインタ渡し** — 関数から戻ると `y` は 11 に変わっている（アドレスを経由して書き換えたから）
3. **`const` ポインタ** — `const int *cp` はポインタを動かせる（左側が `const` だから）、`int * const p_const` は指す先を書き換えられる（右側が `const` だから）

</details>

### 例 2：アドレスと値の関係

アドレスの実際の値や、ポインタ演算を見てみます。

```c
#include <stdio.h>

int main()
{
  int x = 42;
  int *p = &x;

  printf("Variable x: %d\n", x);
  printf("Address of x (&x): %p\n", (void *)&x);
  printf("Pointer p: %p\n", (void *)p);
  printf("Value pointed to (*p): %d\n", *p);

  printf("\n== Modifying through pointer ==\n");
  *p = 100;
  printf("After *p = 100:\n");
  printf("x = %d\n", x);
  printf("*p = %d\n", *p);

  return 0;
}
```

出力例：

```
Variable x: 42
Address of x (&x): 0x7ffc2d5d030c
Pointer p: 0x7ffc2d5d030c
Value pointed to (*p): 42

== Modifying through pointer ==
After *p = 100:
x = 100
*p = 100
```

`p` のアドレス値は実行のたびに変わりますが、`x` のアドレスと一致しています。

## つまずきポイント

**`int * p; printf("%d", p);` でコンパイルエラー**
`p` は初期化されていないポインタ（ゴミ値）です。
`int *p = NULL;` で初期化するか、必ず有効なアドレスを代入してください。

**`*p` の値がおかしい（セグメンテーション違反）**
`p` が `NULL` か無効なアドレスを指しています。
`p == NULL` をチェックするか、`p` が有効なアドレスを指しているか確認してください。

**ポインタを渡したのに呼び出し側が変わらない**
`&` を付けるのを忘れていないか。
関数の定義で `int x` なら値渡し、`int *p` ならポインタ渡しです。

**`error: invalid type argument of unary '*' (have 'int')`**
`*` を変数に付けています。`*p` は OK だが、`*x`（`x` が `int` の場合）はエラー。

**`const int *p` と `int * const p` の区別がつかない**
左側の `const` を読んでください。
- `const int *p` — 左側は `int` なので「`int` が `const`」
- `int * const p` — 左側は `*` なので「`*`（ポインタ）が `const`」
