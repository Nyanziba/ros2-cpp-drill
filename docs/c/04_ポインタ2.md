# 4. ポインタ② — 配列とポインタ演算

> **この章のねらい**: C の配列は、関数の引数として渡すと「ポインタ」に変換（減衰）されます。この結果、`sizeof(配列)` で配列全体のサイズが取れなくなり、関数が「何個の要素があるか」を知る手段を失います。ポインタ演算 `p + 1` は「1 バイト」ではなく「指す型のサイズぶん」進むので、`int *` と `char *` で動作が違います。範囲外アクセスは C のコンパイラやランタイムが止めてくれず、静かにメモリを壊します。Address Sanitizer を使うと、このような違反を捕まえられます。

## 4.1 配列名が先頭要素へのポインタに減衰

**配列は、式として使われると「先頭要素へのポインタ」に自動変換される。**

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;  // arr は &arr[0] に減衰する
```

`arr` と `&arr[0]` は同じアドレスを指します。

```
arr = 0x7ffd6afc8570
&arr[0] = 0x7ffd6afc8570
p = 0x7ffd6afc8570
```

**ただし例外がある。** `sizeof(配列)` や `&配列` のときは減衰しません。

```c
sizeof(arr)       // 配列全体のサイズ（減衰しない）
&arr              // 配列へのポインタ（減衰しない）
```

一方、配列を関数に渡すと、必ず減衰します。

## 4.2 ポインタ演算 — 型に応じた増分

**`p + 1` は「1 バイト進む」のではなく「指す型のサイズぶん進む」。**

たとえば `int *` と `char *` を比べます。

```c
int int_arr[3] = {100, 200, 300};
int *int_p = int_arr;

char char_arr[3] = {'a', 'b', 'c'};
char *char_p = char_arr;
```

`int_p` を進めた場合：

```
int_p = 0x7ffd6afc8564
int_p + 1 = 0x7ffd6afc8568
差分: 4 バイト（sizeof(int) = 4）
```

`char_p` を進めた場合：

```
char_p = 0x7ffd6afc85c5
char_p + 1 = 0x7ffd6afc85c6
差分: 1 バイト（sizeof(char) = 1）
```

**ポインタ演算は「要素数ぶん」を単位とする。** この仕組みのおかげで、配列の要素を順番にアクセスできます。

## 4.3 `sizeof(配列)` と `sizeof(ポインタ)`

**配列と、その先頭へのポインタは別物。**

```c
int my_arr[5];
int *my_ptr = my_arr;

printf("sizeof(my_arr) = %zu\n", sizeof(my_arr));  // 20 (5 * 4)
printf("sizeof(my_ptr) = %zu\n", sizeof(my_ptr));  // 8 (pointer size)
```

実測値：

```
sizeof(my_arr) = 20 (entire array)
sizeof(my_ptr) = 8 (just pointer)
```

**配列の要素数を計算するには。**

```c
size_t num_elements = sizeof(my_arr) / sizeof(my_arr[0]);  // 5
```

実測値：

```
my_arr / sizeof(my_arr[0]) = 5 (number of elements)
```

この計算は「配列に直接作用している場合だけ」有効です。ポインタに対しては使えません。

## 4.4 配列を関数に渡すと要素数が失われる

**配列を関数に渡すと、自動的にポインタに減衰する。結果として、要素数が分からなくなる。**

```c
void print_array_broken(int *arr)
{
    printf("sizeof(arr) = %zu\n", sizeof(arr));  // 8（ポインタサイズ）
}

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};
    printf("sizeof(data) = %zu\n", sizeof(data));  // 20（配列全体）
    print_array_broken(data);  // ここで減衰！
}
```

実測値：

```
In main:
  sizeof(data) = 20
  Elements: 5
Inside function:
  sizeof(arr) = 8 (not the array size!)
```

**関数内では要素数が分からないので、別途「要素数」を引数で受け取る必要がある。**

```c
#include <stdio.h>
#include <stddef.h>   /* size_t */

void print_array_safe(const int *arr, size_t n)
{
    for (size_t i = 0; i < n; i++) {
        printf("arr[%zu] = %d\n", i, arr[i]);
    }
}

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};
    print_array_safe(data, sizeof(data) / sizeof(data[0]));
}
```

実測値：

```
Inside function:
  n = 5 (elements)
  Printing elements:
    arr[0] = 10
    arr[1] = 20
    arr[2] = 30
    arr[3] = 40
    arr[4] = 50
```

**マイコン制御では、バッファサイズは絶対に失ってはいけない。** 要素数は引数で必ず渡してください。

## 4.5 配列添字は `*(a + i)` の糖衣

**`a[i]` と `*(a + i)` は、コンパイラレベルで同じ。**

```c
int test_arr[5] = {10, 20, 30, 40, 50};
printf("test_arr[2] = %d\n", test_arr[2]);
printf("*(test_arr + 2) = %d\n", *(test_arr + 2));
```

実測値：

```
test_arr[2] = 30
*(test_arr + 2) = 30
```

配列にしろポインタにしろ、添字操作の内部は「ポインタ演算 + 間接参照」です。

## 4.6 範囲外アクセス — 静かに壊れ、ASAN で捕まる

**C には「配列の境界チェック」がない。範囲外読み取りは、ゴミ値を返すだけ。**

```c
int arr[5] = {10, 20, 30, 40, 50};
printf("arr[5] = %d\n", arr[5]);  // 範囲外（未定義動作）
```

## 手元で試す

配列の減衰、ポインタ演算、`sizeof` の違い、関数引数での喪失、範囲外アクセスを実際に確認します。

```c
// pointer_arithmetic.c
#include <stdio.h>
#include <string.h>

// 安全な合計関数
int sum_array(const int *arr, size_t n)
{
    int total = 0;
    for (size_t i = 0; i < n; i++) {
        total += arr[i];
    }
    return total;
}

// 範囲外アクセスのデモ
void out_of_bounds_demo(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("  Valid: arr[0]=%d, arr[4]=%d\n", arr[0], arr[4]);
    printf("  Out of bounds:\n");
    printf("    arr[5]=%d\n", arr[5]);
    printf("    arr[6]=%d\n", arr[6]);
}

int main(void)
{
    printf("=== Array-to-pointer decay ===\n");
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;
    printf("arr == &arr[0]: %s\n", (void *)arr == (void *)&arr[0] ? "yes" : "no");
    printf("p points to arr[0]: %d\n", *p);

    printf("\n=== Pointer arithmetic ===\n");
    int int_arr[3] = {100, 200, 300};
    int *int_p = int_arr;
    printf("int: int_p = %p, int_p+1 = %p (diff: 4 bytes)\n",
           (void *)int_p, (void *)(int_p + 1));
    printf("sizeof(int) = %zu\n", sizeof(int));

    char char_arr[3] = {'a', 'b', 'c'};
    char *char_p = char_arr;
    printf("char: char_p = %p, char_p+1 = %p (diff: 1 byte)\n",
           (void *)char_p, (void *)(char_p + 1));
    printf("sizeof(char) = %zu\n", sizeof(char));

    printf("\n=== sizeof(array) vs sizeof(pointer) ===\n");
    int my_arr[5];
    int *my_ptr = my_arr;
    printf("sizeof(my_arr) = %zu\n", sizeof(my_arr));
    printf("sizeof(my_ptr) = %zu\n", sizeof(my_ptr));
    printf("Elements in my_arr: %zu\n", sizeof(my_arr) / sizeof(my_arr[0]));

    printf("\n=== Array subscript == pointer arithmetic ===\n");
    int test_arr[5] = {10, 20, 30, 40, 50};
    printf("test_arr[2] = %d\n", test_arr[2]);
    printf("*(test_arr + 2) = %d\n", *(test_arr + 2));

    printf("\n=== Safe array processing ===\n");
    int data[5] = {10, 20, 30, 40, 50};
    size_t n = sizeof(data) / sizeof(data[0]);
    int total = sum_array(data, n);
    printf("Sum of %zu elements: %d\n", n, total);

    printf("\n=== Out-of-bounds (without ASAN) ===\n");
    out_of_bounds_demo();
    printf("Program continues even after reading garbage...\n");

    return 0;
}
```

## つまずきポイント

**`sizeof(arr)` を関数内で取って、配列サイズを計算しようとする**
配列が関数に渡されると、ポインタに減衰するので、`sizeof` はポインタサイズ（通常 8 バイト）を返します。要素数は別途引数で受け取ってください。

**ポインタ演算の結果が予想と違う**
`p + 1` が「1 バイト」進むのではなく「指す型のサイズぶん」進むことを確認してください。`int *` と `char *` で異なります。

**範囲外アクセスで値が毎回変わる**
未初期化メモリを読んでいるので、値は実行ごとに異なります。「この値が出る」と決め打ちするのは危険。ASAN を使ってください。

**`p[i]` と `*(p + i)` の違い**
C では同じです。どちらを使ってもコンパイラは同じコードを生成します。
