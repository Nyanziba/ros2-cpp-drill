# 1. ヨー角の融合

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/autonomy/01_ヨー角の融合.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/autonomy/01_yaw_fusion.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/autonomy/01_yaw_fusion.html

ホイールのヨーはスリップで飛び、ジャイロのヨーはゆっくりドリフトします。試合中の向きは、ジャイロを主にして、ホイールを少しだけ混ぜます。大きく食い違ったホイールは捨てます。robot_localization の EKF を起動する代わりに、同じ考え方の式と、2D 用の ekf.yaml を採点します。

## 式

角度は必ず [-pi, pi] に畳んでから差を取ります。予測は `wrap(previous + gyro * dt)`、融合は `wrap(predicted + 0.02 * wrap(odom - predicted))` です。係数 0.02 は 1-0.98 です。ゲートの外なら予測をそのまま返します。

| 項目 | 決まり |
| --- | --- |
| odom0_config | x, y, yaw, vx, vyaw だけ true |
| imu0_config | yaw, vyaw, ax だけ true。重力は除去する |

## yaml

`frequency: 30.0`、`two_d_mode: true`、`world_frame: odom`、`odom0: /odom`、`imu0: /imu` を含めます。config の15個の真偽値は1行で、テストが部分文字列として探します。

```cpp
double fused = fuse_yaw_gated(previous, odom_yaw, gyro_rad_s, dt, gate_rad);
```

## CI でやらないこと

ekf_node の起動は `GTEST_SKIP` です。TF と実センサが要るためです。採点は式と yaml です。

## 対応する課題

```bash
./drill run nav01
```
