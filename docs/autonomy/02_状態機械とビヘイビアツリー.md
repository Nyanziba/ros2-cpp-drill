# 2. 状態機械とビヘイビアツリー

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/autonomy/02_状態機械とビヘイビアツリー.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/autonomy/02_state_machines_and_behavior_trees.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/autonomy/02_state_machines_and_behavior_trees.html

3 分の試合には、開始、探索、接近、設置、終了のように、戻れる場所が決まっている流れがあります。これは状態機械が向いています。障害物回避のように、毎周期「今どれが一番大事か」を選ぶ処理はビヘイビアツリーが向いています。ゾーンまでの走行は、状態の中から木を tick します。

## 遷移

WaitStart は StartSignal で Search です。Search は MarkerSeen で Approach、Approach は Aligned で Align、Align は Placed で Place、Place は Scored で Finished です。Approach、Align、Place の MarkerLost は Search に戻ります。TimeUp は Finished 以外を TimedOut にします。Finished の TimeUp は Finished のままです。TimedOut と Finished は他のイベントでは動きません。

| 項目 | 決まり |
| --- | --- |
| 試合の相 | StateMachine |
| 障害物回避 | BehaviorTree |

## 使い分け

`choose_controller` は MatchPhase を状態機械、ObstacleAvoidance をビヘイビアツリー、DriveToZone を「状態機械がビヘイビアツリーを呼ぶ」にします。全部を片方に寄せないのが、この章の結論です。

```cpp
MatchState state = next_state(current, event);
Controller which = choose_controller(task);
```
