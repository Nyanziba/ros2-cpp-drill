# 3. 経路と復帰

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/autonomy/03_経路と復帰.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/autonomy/03_routes_and_recovery.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/autonomy/03_routes_and_recovery.html

残り時間より長い経路は、最後の得点に間に合いません。地図から機体までの座標も、map から base_link へ直行させず、odom を挟みます。Nav2 と slam_toolbox の起動は CI ではスキップし、時間の判定、TF の並び、SLAM のモード名、復帰 XML を採点します。

## 時間とフレーム

地点が1つ以上、負の区間が無く、区間の合計が残り時間以下（1e-9 の余裕つき）なら feasible です。不成立でも名前と合計は埋めます。TF は map から odom、odom から base_link の直接の辺が両方要ります。地図が既にあり追記しないときだけ localization、それ以外は mapping です。

| 項目 | 決まり |
| --- | --- |
| feasible | 空でなく、負の区間がなく、合計 <= 残り時間 |
| SLAM | have_map かつ not keep_mapping なら localization |

## 復帰

スタックしたときの XML は、下の文字列と完全一致です。Spin の行は with_spin のときだけ入れます。インデントと末尾改行も一致させてください。

```xml
<RecoveryNode number_of_retries="1" name="FieldRecovery">
  <Sequence name="primary">
    <Wait wait_duration="0.5"/>
  </Sequence>
  <Sequence name="recovery">
    <BackUp backup_dist="0.30" backup_speed="0.15"/>
    <Spin spin_dist="1.57"/>
  </Sequence>
</RecoveryNode>
```

## CI でやらないこと

地図もシミュレータも起動しません。Nav2 の recovery ノードを実際に tick するテストは `GTEST_SKIP` です。

## 対応する課題

```bash
./drill run nav03
```
