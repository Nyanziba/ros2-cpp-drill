# 6. 視線制御

- 日本語: https://nyanziba.github.io/ros2-cpp-drill/vision/06_視線制御.html
- English: https://nyanziba.github.io/ros2-cpp-drill/en/vision/06_gaze_control.html
- 中文: https://nyanziba.github.io/ros2-cpp-drill/zh/vision/06_gaze_control.html

人やマーカーが画像に写ったら、カメラか頭部のパンとチルトをそちらへ向けます。画像処理のシリーズに置いたのは、入力が検出結果だからです。モードの切り替えだけビヘイビアツリーに任せ、角度の計算は普通の関数にします。

## 誰を見るか

rank は小さいほど優先です。0 が競技対象、1 が人、2 がその他です。より小さい rank は、今の対象を見失いかけていても即座に乗り換えます。同じ rank の、スコアが高いだけの対象には乗り換えません。見失いは 5 回連続まで保持し、5 回目の欠測で外します。

| 項目 | 決まり |
| --- | --- |
| パン | kp * (cx - width/2) を ±max_rate で挟む |
| チルト | 画像の y は下向きなので、kp * (cy - height/2) の符号を反転する |

## 木のモード

黒板の `estop` が真なら `hold`、そうでなく `target_visible` なら `track`、どちらも無ければ `search` です。XML には Fallback と Sequence を含めます。角度の積分と制限は `update_gaze` の側です。

```cpp
GazeMemory next = update_gaze(previous, detections, camera);
// gaze_mode: hold, track, or search
```
